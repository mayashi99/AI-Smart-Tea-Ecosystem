# Database Setup

## Database Name
smart_tea_ai

## Steps

1. Create a PostgreSQL database named `smart_tea_ai`.
2. Open pgAdmin.
3. Run `create_tables.sql`.
4. Import datasets from the `datasets/` folder.
5. Run `seed_data.sql` (optional).

## Tables

- users
- tea_batches
- auction_prices
- export_volumes
- exchange_rates
- climate_data
